# Diplom_1

Автоматизация юнит-тестирования сайта Stellar Burgers
в рамках обучения по программе подготовки тестировщика-автоматизатора
Яндекс.Практикум


| Технология    | Версия | Примечание                                                                                  |
|---------------|--------|---------------------------------------------------------------------------------------------|
| Java          | 11     | Язык программирования, использованный в проекте.                                            |
| JUnit         | 4.12   | Фреймворк автоматизированного тестирования, команды которого использовались в проекте       |
| Mockito       | 3.12.4 | Фреймворк для создания заглушек и моков в автотестах                                        |
| Byte Buddy    | 1.11.6 | Java-библиотека для  создания классов Java в рантайме (нужна для корректной работы Mockito) |
| JaCoCo        | 0.8.11 | Фреймворк для генерации отчётов покрытия классов Java и их функциональностей автотестами    |
